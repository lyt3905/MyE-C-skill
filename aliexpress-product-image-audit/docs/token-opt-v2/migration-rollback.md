# token-opt-v2 迁移与回滚

## 迁移
保留v1基线ZIP，先在隔离测试环境执行全部离线测试。v2统一从workflow_runner.py进入，默认read_only。不要调用旧CLI --apply，该入口现已拒绝正式写入。规则与预算配置位于scripts/config；本轮配置是从既有规则提取的声明，旧v1函数仍保留自身判据以保护兼容性，尚未全部改为读取配置。

AI密钥仅在环境或受保护凭证提供；执行器签名密钥和nonce数据库放在独立账号保护目录。完成独立Windows用户、文件ACL、限制网络及可信IPC部署后方可考虑生产。代码中的同用户摘要和HMAC不能阻挡拥有相同文件权限的Agent。不得直接向Agent提供签名密钥。

check_template_sync.py已递归覆盖AI/执行器/config正式文件，只校验不会写副本。不要默认push到本机技能目录；先审查差异。部署副本尚未同步不等于代码测试失败。

## 回滚
停止任务，保留Job、nonce数据库、授权与回读收据；不要重复使用票据或自动重放已执行任务。baseline-v1.zip包含基线跟踪文件，仅在独立回滚目录解压并运行原12项测试，不覆盖工作目录和凭证。真实商品回滚需要依据product_before和现状重新编制计划并获得新授权，不自动执行反向写入。
