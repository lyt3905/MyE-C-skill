# token-opt-v2.1 状态报告

本轮未执行任何生产写站、账户创建或 ACL 修改。离线测试不能证明真实账户隔离及审核质量。

已实现：旧写站拒绝、显式只读客户端与 TLS；编译器白名单与证据哈希；review-submit 数据绑定；live-dry-run；SID 验证 IPC 回执及状态链；残差证据；标题语义和显式身份候选、SKU 缺图复核；描述不确定 URL 阻断；业务分类；并发和内容缓存；流式下载与配置预算。

部分实现：人工复核数据由显式命令提交，不能据此证明可信操作人身份；商品身份目前按明确异常触发；店铺会话前后校验，要求独立 shop-scoped 会话，未证明服务端无全局 ABA 竞争；特权传输 Python 私有类不是 OS 隔离。执行器预算由 IPC 配置注入，但部署需确保数据库不可被 Agent 修改。

未完成外部验收：真实 Windows 独立 SID/有效权限、跨账号管道服务验证、20–30 商品人工标签和 v1 对照。
