## 2. 模型配置

模型接口读取VLM_BASE和VLM_API_KEY。默认双模型仍为glm-5v-turbo、kimi-k3-1；Deepseek只做过独立比较，不代表默认双判已被替换。供应商缺失usage记UNKNOWN，不伪造零Token。

密钥只在本机输入，命令记录中不放明文；关闭窗口后进程环境失效。以下输入不会显示字符：

```powershell
$env:VLM_BASE = 'http://127.0.0.1:8788/v1'
$vlmSecret = Read-Host '输入本机模型网关密钥' -AsSecureString
$vlmPtr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($vlmSecret)
try { $env:VLM_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($vlmPtr) }
finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($vlmPtr); Remove-Variable vlmSecret,vlmPtr }
```
