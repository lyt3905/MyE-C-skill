# SKU图片分组选图修正

用户要求：无盒SKU取已审核合格非盒照；有盒SKU优先合格盒照；无可用盒照则使用另一张不同内容的非盒照。已有字段/置信度/同款记录策略不变，不制造SKU或包装内容。旧全局boxes分支只更新有盒行，导致无盒行错误引用未纠正。

复用select_v2及现有SKU行哈希绑定、Plan、LocalExecutor、ExecutionLedger、独立回读。先红绿测试覆盖混合盒/非盒、无盒回退、不可用照片、行顺序和真实ID/无ID；通过相关V2回归。当前5099沿用已明确授权创建独立SKU纠正Job，只读取原封存模型结果，不重复模型调用、不复用旧Job执行/预算；新快照和所选URL字节重新核验。仅改SKU图片池及图片引用，一次保存、零上传，主图/详情/正文及规格价格等保护。

为该纠正Job在现有plan_compiler内增加受限编译入口，从封存审核读取来源并独立重新选择；原回复保留在原Job，以SHA引用，不复制成新审核。计划绑定来源摘要与选中图片字节，写前再次核验来源。用同一执行器和账本保存，独立新登录回读并按每行可见包装状态核验。原“20引用字节一致”证据保留为历史结构/字节检查，不冒充已检查无盒/有盒语义正确。
