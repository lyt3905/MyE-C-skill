# 已知保存成功的部分任务续办

旧行为：整件图片仍有下载失败时，即使本次计划的删除已经保存并独立回读，执行账本也处于CONTENT_REVIEW_REQUIRED，后续不同的整改计划被一律阻止。

0.2.9保留原claim默认阻止规则，增加显式claim_followup入口。只有新的范围授权、不同Job/操作、独立新登录证据以及完全匹配的当前状态，才能启动后续计划。

prepare_partial_followup在独立目录复制必要的执行证据并重新只读验证，不改旧Job。validate_partial_followup要求旧保存明确APPLY_MATCHED、一次保存、账户/商品/店铺/计划哈希匹配、实际变更和保护字段全部通过，且剩余失败仅限旧初审中本来就无字节的未改引用。任何已知图片字节失败、数据漂移或保存未知均拒绝。

claim_followup在同一事务中将旧执行记录完整追加到execution_followups表，再为不同操作保留RESERVED。旧业务仍记录INCOMPLETE，不改为AUTO_VERIFIED；预算/原回复不重置。保存结果未知、已保留操作和重复执行仍被原规则阻止。后续仍须通过现有LocalExecutor的账户、状态、策略及证据校验，不能重复旧Job的保存。
