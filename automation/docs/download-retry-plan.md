# 图片下载重试：设计与实施

沿用download_unique和正式V2 download_only，不新建下载器。用户已要求连续实施，不分阶段确认；单Agent，不提交推送，旧Job只读。

低层接口保留默认零重试以兼容历史调用；正式V2默认开启3次额外重试。429、408和临时5xx、连接超时可重试；404、认证/证书错误、非法图片不重试。等待按2/4/8秒递增，遵守数值或HTTP日期Retry-After，同主机请求共享冷却。服务器要求等待超过60秒时记录下次允许时间，不提前请求。成功缓存及SHA继续复用，失败临时文件清理，每次尝试单独记录。

配置local/download.local.json，初始化只补不存在文件。download_only冻结本次下载设置并保存下载结果/计数；旧模型重试设置保持0。实际补下载仅限5094此前未读引用，新目录、新记录，不改旧审核结果，也不因下载成功就声称审核通过。

步骤：先增加瞬时429后恢复、缓存保留、重试耗尽、Retry-After日期/长等待、404/坏图片不重试及正式入口配置测试；确认失败后修改现有下载器和配置初始化。相关离线回归通过后进行一次5094失败引用补下载；最后构建独立安装包并做源码不可访问的相关测试，记录结果及未完成项。
