# 保留模型明确的整张宣传图删除结论

> 0.2.19起图片属性与动作采用[模型直接决策](model-directed-images.md)。以下历史边框/类别判别说明不再作为程序二次裁决依据；七张主图、SKU分配与受限保存等固定规则保留。

0.2.12 修复5185主图1暴露的问题。DeepSeek原始结论为DELETE，结构化类别为DECORATED_COMPOSITE，标明店铺宣传边框和底部宣传条。旧程序只把顶部及两侧细框计入可移除面积，漏计归属UNKNOWN的底部SELLER_NOTICE，因未达到另一条面积规则而改成REMOVE_TEXT，再被未知文字规则拦成REVIEW。

现在，当模型没有弃权、明确判DELETE、类别为DECORATED_COMPOSITE，并记录非受保护、贯穿画面边缘的OTHER_STORE_FRAME时，既有宣传拼图识别函数保留这项整图删除结论。贯穿指框沿画面边缘横向或纵向跨度至少80%；不再因细框面积小或局部文字归属未知而降级。只接通这项明确模型判断，未关闭所有业务规则，未用程序猜测文字归属，未修改Prompt。小标记、厂家横幅及中部宣传文字不能仅凭标签触发新分支。

普通商品照片的小标记分支、模型明确REVIEW/弃权、UNKNOWN类别、包装未确定、厂家/商品/包装印刷保护仍沿用已有处理；修复后是否可执行删除仍受原有动作授权、包装证据保护、同照片干净版本优先和独立回读约束。原AI回复不修改。

同一识别函数同时服务新初审和已有只读结果的离线复算，避免只改报告显示而实际调用链继续误降级。新版本复算五商品的76份既有回复，仅5185主图1从REVIEW恢复为原始DELETE，其余75份不变，待复核5→4。新结果单独记录在reports/poster-delete-fix-20261116/reassessment.final.json，旧五个Job及账本保持完整。
