# 水印商品图：替换或去字优先

0.2.20修订了正式DeepSeek图片审核提示词，修正5173暴露的“重复店铺水印＋厂家原有边框被当作店铺宣传拼版”问题。Python执行器不增加内容判断，仍按AI的顶层动作及逐区域指令处理。

- 有商品价值的照片或厂家商品宣传素材，即使覆盖多处店铺水印，也不因此整图删除。人物/车辆/包装多视图拼图、厂家边框、型号名称、产品标题、厂家标识及原型免责声明本身都不是店铺广告的证据。
- 识别出新增水印后，优先使用已有同原图干净版本；否则给出可执行去字区域。风险高、缺少安全几何、修复不可用或质量失败时保留待复核，不自动改成删除。
- 整图宣传删除必须有独立于叠加水印的店铺商业信息，例如店铺介绍、店铺现货/折扣/购买横幅与店铺品牌组合。不能把水印中的店名和厂家原图的边框重复计为两份店铺广告证据。
- 纯空白/不可用图、没有可复用价值的纯店铺广告/购买/联系通知仍可DELETE；通用规格、尺寸、产品说明及包装/运输说明不因没有玩具照片而自动删除。
- 模型如实记录未知归属和真实风险，不降低风险标签或伪造坐标。厂家印刷和结构像素、图片修改授权、尺寸格式、SKU引用及保存回读等既有保护继续执行。

正式提示词：[image_action_decision.v2.md](../src/mye_c_automation/prompts/image_action_decision.v2.md)。旧的多段追加规则已合并，业务提示词实际文件从14893字节缩减到10347字节。完整JSON Schema仍随请求附带，ID/evidence/区域动作/置信度仅记录等协议不变。未修改模型输出上限、重试策略或并发。

新的提示词自动改变既有缓存键，因此后续新审核不会把旧提示词的DELETE缓存当成新判断；旧缓存、原始回复、Job和账本保留。历史5173的6份DELETE原回复仍是历史错误观察，没有被改写成新的REMOVE_TEXT或通过结论。

本轮只做离线/安装包/Fake验证，真实模型新规则效果尚未复验；5173线上已删除的图片没有在本轮恢复，已有待处理项也没有补跑。不能把离线流程通过当作新提示词已真实纠正模型输出。
