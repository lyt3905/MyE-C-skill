# 一次分析、全图定位、最终验收

0.2.24 在原有 V2 主流程上增加全图重复水印定位、共享模型缓存、确定性修复缓存及最多一次残留补修。没有增加第三套审核器、客户端、Runner 或写入器。

DeepSeek 初审为确认可去除的重复水印样式返回一条 TEMPLATE_GLYPHS 指令，显式 glyph_search_scope=IMAGE，指定一份完整、均匀背景上的 glyph_template_bbox 样本。程序提取样本一次，对全图作相同笔画匹配、抑制重叠重复峰值、合并全部可靠匹配的掩膜，再进行一次 LaMa 修复。不是逐个水印询问模型，也不对其他文字作本地语义分类。未指定 IMAGE 时仍只在原有局部范围内匹配。保护区域、格式、掩膜面积和掩膜外像素检查不变；匹配位置记录到修复证据，失败时也保存 mask_geometry.json。

正常的需修复图片路径为一次 DeepSeek 初审、一次最终质量复核。最终复核同时检查整张残留和原商品/包装/印刷/瑕疵，并可返回候选图坐标下的 residual_watermarks。只有明确 MISMATCH、仅水印残留且其他四项均通过、没有弃权，并提供合法可执行区域时，程序才追加一次补修。缺少区域、结构失败或其他未知状态不会自动放行。

补修把新掩膜与前一轮掩膜合并，仍从原图进行 LaMa 推理，并再次与原图作最终质量复核。不会在已修改的候选上反复叠加重绘，也不会无限查询 DeepSeek。原始初审和质量回复不改写，派生执行输入保存在 residual_feedback.json。没有模板可用时，复核可以显式 glyph_template_source=ORIGINAL，复用原图样本定位候选图中的真实残留；默认 CANDIDATE。

缓存沿用既有 ResultCache。正式 V2 审核任务共享已校验的模型结果，模型配置、Prompt、Schema、上下文、图片内容变化均改变缓存键；新 Job 不继承旧预算或授权。修复缓存绑定源图、观察、最终掩膜、算法、模型权重和实现文件指纹，命中后重新检查字节及掩膜外像素。缓存损坏时重新执行本地修复。最终 AI 质量判断仍独立，缓存中的像素候选本身不是通过凭证。

沿用现有图片审核并发；同 SHA 去重，同模板合并匹配，同一准备阶段只加载一次 LaMa。资源密集的本地 LaMa 不擅自增加实例并发。标题审核或其他商品任务的模型调用不计入“单张图片正常两次”的说明。

全图像素匹配不等于证明所有水印均已清除：变形、裁切、不同样式或被商品纹理遮盖的笔画仍可能匹配失败，最后由 DeepSeek 验收；未通过继续待复核，不以整图 DELETE 替代失败修复。历史样本、Jobs、原图、原始思考和账本保留。
