# 重复水印的精细笔画修复

0.2.23 在原有正式 V2 路径增加 TEMPLATE_GLYPHS，不另建审核器、模型客户端、Runner 或写入器。DeepSeek 仍决定内容、动作和保护区域；程序只执行模板笔画提取及几何匹配。

模型为 REMOVE_TEXT 区域返回 repair_mode=TEMPLATE_GLYPHS，以及 glyph_template_bbox=[x0,y0,x1,y1]。模板必须来自同一张图中均匀背景上的一份完整、无遮挡的重复水印；目标为同尺寸同角度的副本。MEDIUM/HIGH 风险如实保留，不再仅因此拒绝精细掩膜试修。明确 REVIEW 或不合格回复仍不能进入修复。

程序校验参考背景、笔画比例和对比度；从参考样本导出颜色投影，对彩色水印抑制不同色相和过强产品色块的干扰，再匹配笔画。允许模型模板框在短边4%内、目标框在短边8%内作有界几何细化；裁掉样本空白边缘，要求至少0.60像素相关度以及0.04的独立匹配差距。这些是图形对齐阈值，不是模型置信度门槛，不用于判断文字归属。所有原始框、细化框、匹配相关度和掩膜像素数随修复记录保存。目标外及保护区域检查、最大25%掩膜面积限制继续生效。

模板模式只使用配置的本地 LaMa；不因失败降级为整块 OpenCV 擦除。原图及 alpha 保留，掩膜外 RGBA 像素必须完全一致。候选继续通过既有 DeepSeek 五项复核：商品结构、包装、保护印刷、水印去除、新增瑕疵。任何一项不通过都不发布。高重叠获准试修不代表真实画质已通过。

限制：不能处理没有完整样本、样本背景混杂、各副本缩放/旋转不同、目标位置严重错误或无法唯一匹配的情况。确切保护区域与水印交叠也会拒绝，不能通过更改原始风险或删去保护坐标绕过。失败保留原图待复核，不转换为 DELETE。历史原始回复及账本不回写。
