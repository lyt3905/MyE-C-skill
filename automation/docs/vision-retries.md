# 视觉初审最多重试三次

2026-11-18，0.2.36。当前本地模型配置以及新的8788配置模板中，vision_retry_limit=3。一个新图片任务最多初次请求1次＋重试3次，取得有效输出后立即停止；不会为凑次数继续请求。旧配置明确0/1或没有该可选字段时，保持原本语义；不改旧Job绑定配置或账本。

只针对现有可重试的临时请求错误、空输出、无效JSON或结构校验错误。程序将缺少的必填字段、多出的字段及本次合法evidence_ids作为纠正信息提供给模型，再让模型自己重新输出。所有失败和成功原回复均留档，不由程序补填证据编号或剥除regarding伪装原输出通过。

Schema仍以原V2业务Schema为唯一来源；模型不支持的字段不加入业务Schema。regarding之类说明应写入已有reason，不新增执行字段。响应失败类型分别记录，额外请求计入原有预算/Token指标。显式更小attempts限制继续有效。

明确保护内容要求擦除、SHA/坐标等业务失败、永久HTTP错误、输出截断和网关不支持等，不靠三次重复问答绕过。局部修复和候选质量流程保留原限制；该设置不取消10%印刷搜索区重建上限，也不把质量失败转成成功。

```json
{
  "vision_retry_limit": 3,
  "retries": 0
}
```

vision_retry_limit为视觉初审的受限重试；retries不是需要同步调大的开关。模型、低强度思考、输出上限、并发、密钥和其他配置保持原值。用户本次要求补试的3条旧失败已各消耗首次请求，因此新补试任务每张最多3次额外请求，不再额外给4次。正常新任务仍按首次＋3次执行。
