# 分级视觉审核与字段精简实施计划

用户已批准的设计：初审只返回decision、visual_class、retail_box_status、sku_suitability、abstain、reason；无干净同图可替换且需要去水印时，再请求watermarks、preserve_regions、reason；实际候选复核保留五项质量检查和残留目标。删除新请求中仅记录的分数、同款/结构/配色观察和内部算法说明。程序绑定ID/SHA/证据，不伪造模型分数或画面属性。旧V2原始记录和读取契约保持。

范围：复用现有JudgeClient/账本、full_product_audit、v2_remediation、修复器和质量复核。新增版本化阶段契约从现有业务枚举派生；不建立另一套Runner/Writer。新网关配置默认staged-v1，显式legacy-v2恢复旧请求；未配置的低层旧客户端保持其库API兼容。首轮REMOVE_TEXT未进入整改时只保留初审，不提前请求坐标。已审批的OCR备选及最多两轮本地候选保持。

执行约束：保留工作区所有既有修改，单Agent；本轮无真实模型、线上访问/写入或Git发布。baseline.json保留开始前源码/测试/文档哈希。每阶段独立验证，旧阶段输出与预算不改写。
