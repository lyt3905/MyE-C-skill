# 模板取样与印刷保护细化

0.2.26 增加已确认图案的残留检查。全图模板匹配继续保持 NCC 0.60 下限，增加原样本笔画与邻域的局部色差、分段支持及独立边缘对齐，以覆盖有色商品背景。仅剩部分笔画时，两个相邻样本片段必须在同一平移位置分别达到 0.60，才可使用同一个原样本笔画掩膜；不识别新文字或推断归属。所有匹配方法及各自真实分数分别记录，不把局部色差分数伪装成 NCC。

质量复核同时检查候选图是否仍匹配初审明确批准的同一水印图案。匹配残留时，即使 DeepSeek 原始回复 MATCH，也记录 FAIL_WATERMARK_REMAINS，不改写原回复。最多3个候选残留局部放大图附在同一次质量请求中。只有其他四项保护检查明确通过且没有弃权时，才允许既有的一次补修；仍从原图修复，掩膜合并，不无限重试。没有匹配只能证明未匹配，最终仍须模型五项验收。

LaMa 后仅对原图掩膜周边足够均匀的独立区域做同色填充，消除纯色背景噪点；95%边界采样与中位色距离不超过8，掩膜外像素不变，复杂商品区域仍由 LaMa 处理。历史误通过候选保留为回归夹具及争议证据，不追改历史账本。

0.2.25 复用原有 V2、LaMa 和质量复核链路，解决“固定扩框混入商品背景”和“整块矩形保护导致空白背景无法去水印”。原图、原始 AI 回复及历史账本不变。

模板仅来自 AI 已确认的同一水印。程序在样本框附近短边6%范围内独立收紧或扩展四边，要求背景边缘仍均匀、前景完整落在内部、有足够对比度且面积合理，再裁掉空白边缘。没有合格样本时，可尝试模型在同一次分析中提供的最多3个 glyph_template_candidates；不把别的文字当新水印，不降低已有匹配阈值。选择索引、实际窗口和笔画完整性检查进入修复记录。

EXACT_REGION 继续保护每个像素。对于模型明确确认的明亮或明亮描边印刷，BRIGHT_PRINT_GLYPHS 从指定搜索框提取明亮笔画并填充闭合字形内部，保护实际字形；无法找到可靠笔画时拒绝，不默认为没有印刷。保留文字在 watermarks 中仍是 action=KEEP，需显式 preserve_mode=BRIGHT_PRINT_GLYPHS；对应 preserve_regions 使用同名 scope。暗色或无法确定的印刷继续 EXACT_REGION。

若水印确实覆盖少量印刷笔画，且已获本地修复授权，可由模型显式指定 PRINT_RESTORE（KEEP 标记的 preserve_mode、保护区的 scope 同步）。这只允许精确 TEMPLATE_GLYPHS 水印笔画局部重建，不允许整框 REGION 擦除；受影响像素不超过该印刷搜索区的10%。掩膜外原像素仍完全一致，最后必须通过 DeepSeek 的 protected_print_preserved 和 no_new_artifacts 等五项检查。不是删除或改写厂家文字的授权，结构不明或印刷大面积缺失仍拒绝。

现有 EXACT_REGION 不会被后台自动降级。对已有观测的人工复核，只能以独立用户执行政策记录派生输入，不能改写为“AI 原本就这样判断”。自动新任务由最新 Prompt 产生显式新模式。当前5173两张图的旧观测可在用户本轮明确同意的范围内做本地试修；候选须单独验收，不能冒充线上整改完成。
