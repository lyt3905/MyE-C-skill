# 人工复核：只删除指定的空白详情图

0.2.13新增受限复核保存通道，复用V3计划、在线预演、执行账本、LocalExecutor和独立回读。入口API为reviewed_images.compile_blank_deletions；需要当前绑定的Job/商品快照、明确用户删除决定，以及每个详情位置的URL和SHA256。程序重新取得字节并确认确为1×1 GIF，保存前再次核对；普通商品图不能进入该通道。

计划只允许reviewed_detail_deletions这一项后置描述、DELETE一个动作，以及“原images仅移除指定detail位置”的结果。不得顺带更换主图、SKU、正文、价格或其他字段。用户复核、输入状态、账号和字节均绑定到计划，执行器在写入前重新校验。

遇到既有主图7～8张时，常规全商品流程仍按1～6张规则检查。只有该通道在证明主图列表完全不变、操作恰为指定空白详情图删除时，允许完成本次局部保存；原有主图超限明确记录为EXISTING_MAIN_COUNT_UNCHANGED，whole_product_verified=false。它不把原有违规判成合规，也不授权删除未复核主图。保存恢复同样保持PARTIALLY_AUTO_FIXED，不能因这次操作成功声称整件审核通过。
